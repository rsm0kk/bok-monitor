## 키

ECOS 키는 이 폴더 `.env` 의 `ECOS_API_KEY` 를 먼저 찾고, 없으면 `../../국장 매크로 모니터/.env` 를 **읽기 전용**으로 빌려 쓴다(값을 복사해 두지 않는다).
FRED 키도 같은 방식 — 이 폴더 `.env` 의 `FRED_API_KEY`, 없으면 `../../미장 요약/.env`.
빌드·배포 때 두 파일의 값이 산출물에 들어 있으면 중단한다.

## 데이터 원칙 (화면 하단에도 표시)

- 값이 없으면 `—`. 0 이나 추정치로 채우지 않는다.
- 2026-09 (E) 는 1~10일 누적 × 20/8 환산치라 **금액만 싣고 M/M·Y/Y 는 산출하지 않는다** (원본 규약). 선형 환산은 월 후반 집중분을 놓쳐 하락을 과장한다.
